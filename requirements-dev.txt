# Everything needed to run the checks in this repository against a checkout.
#
# Floors with closed upper bounds, and each bound carries the reason it exists
# — the same rule the Terraform version constraints follow. A floor alone lets
# a major release change behaviour under an unchanged file; a pin alone means a
# security fix needs a commit here before it can be taken.
#
# The scenario library itself has no runtime dependencies at all, and its suite
# runs on the standard library's own test runner. Nothing below is needed to
# execute a load run; all of it is needed to check one.

# Reads the regression policy. Pinned explicitly rather than relied upon from
# the runner image: the comparison accepts a JSON policy precisely so that a
# missing parser cannot make the gate fail open, and a pipeline should not be
# exercising that escape hatch by accident.
PyYAML>=6.0,<7.0

# Lint. Bounded at the next major on both, because a new default rule set is a
# behaviour change to this repository's own gate.
pyflakes>=3.1,<5.0
flake8>=7.0,<8.0
yamllint>=1.33,<2.0
